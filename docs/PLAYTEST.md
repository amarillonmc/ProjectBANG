# 内测操作手册

## 自定义心象花色与顺序

工坊「03 / 十三张心象」可逐张选择 ♠／♥／♣／♦，也可把整副统一为一种花色；仍要求 A～K 各一张。使用「大点在前」「小点在前」、上下箭头或「移到第几张」安排次序，移动会保留整张牌的效果和花色。未指定花色的旧牌继续视为无花色，花色红黑与攻击冷暖属性无关。保存后，摸心象与选择心象判定均从你排好的牌顶取牌。

建议用全黑桃测试按花色判定技能，再把 K 置顶测试高点判定。技能判定与延时事件判定均可选普通牌池或自己的心象顶；加速防御仍直接用心象顶。花色／牌序属于规则内容，修改后新版本需重新完成作者试用才能投稿。

## AI 斗蛐蛐

1. 大厅点「AI 斗蛐蛐」，选择冷暖、系列或人狼身份模式。冷暖／系列为 2～6 台机器人，身份为 4～7 台。
2. 每个席位单独选择范例或自己的已保存构筑，可重复选同一角色。冷暖／系列至少需要两个阵营，无色各自独立；身份局随机分配身份，允许同色同系列。需要时展开房间预算选项。
3. 「开始斗蛐蛐」直接开局，人类只观战，不占座、不代打。默认正常观战，也可暂停或快速结算。快速结算会跳过中间画面的展示，按相同规则逐步运算。
4. 页面保持开启时自动推进；关闭页面后服务端保存进度，下次重连继续。返回大厅不终止当前观战。人狼只展示已公开身份，结束后全部揭示。
5. 结束后可导出完整复盘。全机器人对局不能替代作者亲自完成一局的投稿验证；当前机器人适合观察交互与寻找问题，胜率不能直接当作强度结论。

## 保存、组系列与投稿

1. 在角色工坊编辑后点「保存新版本」，再进入「我的作品」。新版本默认仅自己可见；再次保存相同内容不重复增版。人物、技能、牌序仍在原工坊编辑，支持 PNG / JPEG 角色图片（最大 2 MiB）。
2. 点身份菜单「绑定新账号」，当前访客的角色、系列、教学和房间一并保留。保存恢复码，换设备时用账号名与密码登录。绑定后原访客备份失效；登录其他账号前，先备份尚未绑定的访客身份。
3. 在作品详情生成链接，朋友可查看固定版本并复制到自己的作品。作品系列可以收录多位角色；分享系列时固定当时的版本组合。之后编辑不会改写已发出的链接。撤回版本会阻止原链接继续访问，已复制的独立作品不受影响。
4. 点「用这个版本试用」，会显示人物、限定总额和单牌预算。超预算版本自动建议足够的房间预算；创建普通房间或机器人练习时也能展开预算选项。完成对局后回作品详情，查看服务器生成的完成记录，然后投稿。胜负都计，可与机器人对局；教学、未结束的局和只让机器人代用角色不计。
5. 投稿库区分标准与超预算。结构检查、预算分类与完成试用分别显示；完成一局不表示强度平衡。修改技能、牌序、角色编号或所属系列等规则内容后，需重做试用；只改构筑名、人物名称、称号与图片不必重测。规则或服务器配置更新后需重测。

内测请重点尝试：跨设备登录、旧访客绑定、重复保存、同时打开两个编辑窗口、分享后继续编辑、系列成员增删、超预算作品加入标准房间、未打完就投稿，以及修改牌序后再次投稿。

## 十分钟熟悉流程

1. 输入昵称建立本地访客身份，在身份菜单备份凭证。备份文件能控制这个席位，不要公开分享。
2. 首页先点「如何玩 · 实操教学」。九节课逐一演练摸牌、自疗、两种损伤、回避叠放、心象判定、心坏恢复、弃牌和胜负；可重试本课，也可选择课程重练，刷新后继续。教学使用独立练习状态，不占用真人房间。
3. 摸牌时选一张心象替换，确认自己拿到的是编排在第一位的心象。剩余心象的顺序在自己的面板查看。
4. 点击手牌阅读效果；需要目标的牌先选择目标，双模式事件选择发动方式，再确认执行。需要代价时按提示指定。
5. 受到攻击时选择防御手牌、成熟装备，或者承受。暂时不适用的动作由服务器拒绝，不会扣牌。
6. 安装两张同类延时基本牌，观察每张的成熟提示和逐张消耗。拳击默认下次自己的回合成熟，其他现有延时基本牌默认立即成熟。
7. 结束回合；若超出手牌上限，选择弃牌后提交。
8. 对局中可查看日志、提交反馈，结束后导出对局数据。

教学之后，从「开始练习」进入完整对局。内测时尽量让新人独立操作，记录在哪一课或哪一步需要旁人解释，尤其是「精神减少」与「身体上限减少」、「同色攻击回复自己」、以及「判定时选择心象顶」能否被主动发现。牌桌的颜色标签同时使用文字，点击不可用手牌也会显示原因。

## 用十六题做出第一位角色

「如何做 · 16 题心象问答」前十二题共同决定主、副打法倾向，最后四题选择冷暖与翻面、身体与费用取舍、心象顺序及第二张限定心象。答案暂存在当前浏览器，可返回修改；这是一种创作引导，不是人格评估。

结果包含两至三项现有拼图技能、十三张 A～K 有序心象（含两张限定牌），并展示打法、弱点、首三张心象和服务器预算。点击「带入工坊 · 编辑、保存与试用」，按引导修改人物、技能、心象顺序和预算，再保存构筑。回大厅选中已保存构筑后即可出战。问答通过预算代表可提交，实际强度仍需要真人对局检验。

## 邀请真人

创建房间，选择冷暖、系列或人狼身份，并决定是否允许自创构筑。将六位房间码发给测试伙伴，由其输入昵称与构筑后加入。房主可加入机器人补足席位：冷暖／系列需要 2～6 席，人狼需要 4～7 席。只有冷暖／系列会检查相互对抗的颜色或系列。

人狼单人测试：点「开始练习」→「练习模式：人狼身份」，选择 3～6 名机器人，默认五人局。看牌桌顶部自己的身份目标；其他玩家仅公开村长，阵亡后揭示。重点反馈身份目标是否清楚、回复牌是否足够，以及《援药》等待一轮成熟是否值得。攻击只扣体力、不削上限，同色可以攻击且不能自疗；濒死时可以选择自救、卸药援救或放弃。

单人测试点击「开始练习」，选择自己的出战构筑、1～5 名机器人及每名机器人的构筑，再开始对局。下拉列表分为角色库与「我的已保存构筑」；自创角色需先在工坊保存。默认一名异色机器人，同色机器人可作为伙伴，但至少保留一名异色对手。私人房间的「加入机器人」同样可以选择构筑，并遵守房间是否允许自创的设置。机器人按当前颜色避开同色目标及可能误伤伙伴的群体牌，翻面后重新判断；系列模式同时避开同系列目标。

没有公网主机时，本机的 `127.0.0.1` 仅自己可访问。公网内测应按部署文档上传到 HTTPS PHP 主机；不能把 localhost 链接发给别人当成已部署地址。

同一浏览器的标签页共用身份；模拟两名真人请使用两个浏览器或两个独立配置。对局进行时离开页面不会撤销座位，响应和回合会按时限处理，恢复后回到原房间。房间列表提供重新进入路径。

## 测自创构筑

从示例复制，修改一个技能或一张限定心象，保存一个能识别版本的名字，如“纸城·摸牌1-v2”。先通过预算，再做以下检查：

| 测试 | 观察 |
| --- | --- |
| 首回合 | 是否过快用完有限心象，是否不需要权衡就必开技能 |
| 受伤与防御 | 被动时机是否符合描述，费用是否清楚 |
| 心坏 | 技能/治疗/范围正确停用，恢复心象能否解除 |
| 异色翻面 | 精神与身体关系是否易懂，阵营变化是否正确 |
| 系列不匹配 | 限定牌是否使用普通替代规则 |
| 多人 | 群体收益、直接伤害、护盾价值是否随人数失衡 |
| 网络恢复 | 刷新、短时离线、重复点击不重复支付，不暴露别人牌 |

机器人会按有限策略做合法动作，不适合用几局胜率给角色打最终平衡结论。真人对局尽量轮换座位和先后手，不只记录胜者。

## 反馈格式

建议包含：房间码、规则版本、使用构筑、回合、刚执行的操作、期望结果、实际结果、是否能重现。不要附访客凭证或数据库密码。系统反馈会写入服务器数据库；管理员可用数据库面板读取，或使用命令行工具导出。

已结束对局的导出可以包含完整最终状态，适合调试；公开分享前注意玩家昵称。进行中的导出会隐藏其他人的手牌/心象，不能用它作弊。
