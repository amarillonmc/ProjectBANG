# 三国杀四扩展技能研究与可复用拼图

核验日期：2026-09-27。实现规则：0.3.0-alpha。机器可读版本为 [sgs-expansion-templates.json](sgs-expansion-templates.json)，含 30 个 `sgsx_` 模板，每项保存武将、扩展归属、所采用技能版本、官方来源、原效果摘要、实际改编与可直接校验的 `skill` 对象。

这些是供魔法纪录角色配装、也供其他 IP 创作者修改的有界改编。它们遵守本项目的冷暖/系列伤害、十三张心象、两技能、全局回合次数和 18 点人物预算；不会冒充《三国杀》的完整技能裁定。全部模板单独装入 4 体力人物时预算不超过 8，因此两模板组合仍有余地配置人物体力。条件不抵扣预算，费用与次数按服务端计价。

## 创作者可以复用的新增机制

新增四种效果 `sequester_hand`、`discard_equipment`、`damage_guard`、`hand_lock`，新增四个时机 `on_targeted`、`ally_targeted`、`after_play_card`、`after_lose_equipment`，新增九个条件：用牌达到二/三/有效体力、首次用牌、连续同点数或花色、首次/再次受伤、有装备、手牌同红黑。全部通过同一服务器元数据进入工坊，不需要手写脚本。

完整行为、目标约束、卡牌选择与到期时间见 [SKILLS.md](../SKILLS.md)。关键裁定如下：

- 暂置手牌属于持有者的私密区域，保留实体 UID 与心象原所有者。持有者出局、正常回合末、施加者回合中出局、提前胜负和 300 回合平局均有明确清理路径。观星等回合末响应结束后才归还。
- 封手覆盖实体出牌及转化出牌、手牌防御、攻守同盟和潜能攻击响应。它不禁止交牌、弃牌、技能手牌费用和已装备防御；到当前全局回合末统一解除。
- 持续减伤在护盾前计算，不消耗、上限二，持续至受益者下一次自身回合开始；失体力绕过，较大伤害能突破。怀橘每轮消耗有限心象，心坏后不能继续补充。
- 装备损失先结算该组效果及宝藏反噬，随后触发存活角色的失装技能；关联目标是实际移除者。主动自弃的装备不足会拒绝整次行动；经过响应边界后资源被移走则按无效后续处理。
- 用牌统计的是主动使用的实体手牌，响应及虚拟攻击不计；无花色心象不被误当成角色冷暖色。实际正伤害才增加受伤计数，完全减免与失去体力都不计入。

规则版本从 0.2 显式升级到 0.3，仅补齐这些新增状态字段；旧的牌区、伤害与已用次数保留。构筑也继续接受缺版本、0.1 与 0.2，输出 0.3，拒绝未知版本。人物/心象总预算 18/24 和单卡 12 均未放宽。

## 验证

`php tests/expansions.php` 检查全部模板的官方来源字段、四包覆盖、唯一 ID、单模板预算，并执行新效果、四个时机、九个条件、隐私、卡牌守恒、回滚、暂置归还、到期与响应交错回归。`tests/properties.php`、`tests/engine.php` 与独立 API 引擎审计的实体收集器已纳入暂置牌区；整包角色的自动对局由内容包测试另行验证。
