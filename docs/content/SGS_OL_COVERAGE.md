# 三国杀 OL 机制覆盖审计

目标版本：用户指定的当前《三国杀 OL》。核验日期：2026-09-29。用户进一步确认：**保留本游戏基础规则，技能机制尽量等价还原**。本轮没有新增角色，只改引擎、积木、编辑器和通用示例。现有 IP 角色仍为原改编版。

**验收范围：机制扩展与等价改编，保留冷暖、心象、心坏及两种胜负规则。** 当前有 73 种效果、26 种时机、139 个技能模板（其中 32 个是本轮新增通用示例）。这些数量不能当作武将覆盖率；尚未建立当前客户端完整武将/技能清单并逐技能通过测试，因而不宣称逐字 100% 复刻或给出 SP 覆盖百分比。本表是能力审计与差异清单。

## 本轮已实现并测试的机制

| 能力 | 拼图与验证 | 仍不能推导出的完整复刻 |
| --- | --- | --- |
| 不限次转化、连续攻击 | limit 0 + passive_attacks；实际连续五张红牌攻击，手牌/装备/专属区可作素材 | 虚拟牌仍只可转为无色攻击或防御，没有酒、桃、无懈、顺手、南蛮等所有牌型 |
| 任意张手牌与装备换牌 | chosen/all 费用 + hand_equipment 区域；paid_cards / paid_hand / paid_equipment 分别绑定实际数量，paid_all_hand 支持弃光原有手牌的额外奖励 | 不自动带入某个同名武将的版本规则，需按当前 OL 指定技能配置分支 |
| 持续能力、光环 | 手牌上限、距离、攻击额度、摸牌、减伤、攻击目标限制；来源死亡/心坏即时失效 | 目标限制还不能按牌名、性别、势力、身份、距离例外等任意组合 |
| 明确负面与高体力多技能 | 8 体力、多于两技能、强制负面二选一返还预算 | 未引入董卓整套技能；缺酒、性别和主公技支持 |
| 条件、分支、可选发动 | 数值比较、all/any、choose/branch；事件数量、初始数量、逐点序号；来源/目标/当前回合角色引用；保存响应后续接 | 任意三方关系、花色点数改写和牌移动原因仍需更多上下文 |
| 伤害前修改与转移 | 来源技能→旁观监听→受伤者技能→减伤/护盾→扣血；可增减、改值、取消、改来源及转移，新目标重开窗口；逐点与整次触发独立 | 无色伤害仍按本游戏身体规则处理；没有新增火雷连环等三国杀基础规则 |
| 濒死与死亡 | 濒死自救、旁观濒死监听、死亡清理前遗赠、清理后死亡监听；嵌套事件与重连，事件结束后判断胜负 | 保留奇迹与冷暖翻面裁定；没有引入桃酒依次求救、负体力显示或禁止救援体系 |
| 判定链与改判 | 黑/红/花色过滤、取得成功判定牌、重复询问、替换/交换判定牌；普通延时和加速也进入改判窗口 | 仍缺点数区间、判定实体直接置于专属区、任意判定结果改写及完整时机顺序 |
| 拼点 | 暗选、同时揭示、严格大于胜、平局未赢、胜负分支 | 仍缺多人拼点、替换点数、取得拼点牌及其他角色介入 |
| 专属资源 | 命名标记、私密/公开牌堆、动态计数、存取及牌堆转化；实体守恒、私密性测试 | 不是自动支持不屈、屯田、星舞等全部技能；各自还有触发与牌移动需求 |
| 限定、觉醒与动态技能 | 整局次数、标记阈值、扣上限、实际获得/失去/封锁技能；复制其他角色技能；永久/回合/自身或来源下回合期限；独立稳定计数和多来源到期 | 未建立随机化身武将牌池；本轮只提供可复用机制，不实装左慈等角色 |
| 选多目标、交换 | 自选不重复目标、按顺序结算；全手牌/全装备交换 | 仍缺区域内自选单张移动、指定三方角色关系、分配摸到的牌 |
| 决斗 | 双方轮流响应攻击，失败受伤，续接后续效果 | 不等于具备原三国杀锦囊、无懈、多目标、伤害来源更改等完整体系 |
| 翻面、额外回合、跳阶段 | 行动面与冷暖面分开；额外回合后恢复座次；跳摸/出/弃 | 仍缺插入任意阶段、跳阶段替代效果、精确准备/结束阶段前后触发 |

对应可执行测试：`tests/feedback.php`、`tests/mechanics.php`、`tests/events.php`、`tests/costs.php`、`tests/dynamic-skills.php`。通用模板在 `src/SkillPuzzles.php`，仅提供上述可组合能力，不以原武将名字标为“完整实现”。

## 保留的规则差异与尚缺机制

| 基础层 | 需要补齐与验收的行为 |
| --- | --- |
| 牌事件上下文 | 已有伤害与死亡事件窗口；仍缺统一的牌使用/响应/移动原因、实体上下文和任意角色监听 |
| 基础生命规则 | 按用户确认保留本游戏身体/精神、奇迹救援、心坏与冷暖翻面；不直接套用桃酒、负体力或身份局求救规则 |
| 卡牌操作与虚拟牌 | 任意区域自选移动与分配、牌堆检索/置顶/置底/展示、花色点数改写、借用实体使用、更多牌型及目标合法性 |
| 身份与角色属性 | 性别、魏蜀吴群/其他势力、主公关系、身份技、技能源归属与消失后的清理 |
| 武将牌资源 | 动态技能已经实现；尚缺化身随机池、专属武将牌区域、获得武将牌时的排除与去重规则 |
| 复杂响应 | 连环与属性传导、要求其他角色提供牌、蛊惑/质疑、争议选择、额外目标与取消目标、技能选择顺序 |
| 当前版本验收资料 | 标准、风林火山、一将成名全清单及 SP 覆盖分母；每条记录具体 OL 版本、来源、完整机制、对应配置、正反用例、重连和隐私检查 |

后续逐技能验收应记录当前 OL 的具体文本、可用拼图、基础规则差异和实际测试结果。可执行的“转移伤害”不能用“回血加伤害”冒充；缺少完整机制的技能也不能因存在一个近似模板就标为完整覆盖。
