# 魔法纪录角色资料与卡面参考

本文件是内容设计与图像制作的资料索引，不是已经实装的技能规则。角色摘要为逐页核对后自行归纳；最终玩法以内容包及其规则文档为准。

来源：[魔法少女列表](https://magireco.moe/wiki/魔法少女列表)。核对日期：2026-09-27。固定选取36位普通独立角色，排除泳装、季节换装及其他IP联动。原作五人作为《魔法纪录》普通可用角色保留；晓美焰采用黑长直普通版本，不采用眼镜、恶魔或季节版。

逐页核对人物信息、简介及游戏数据，图片由页面img标签中实际的“5星无框”卡图地址提取；未采用页首Pixiv同人图，也未误用Frame属性外框图层。36张参考均已查看核对。原图仅留在被忽略的var/magireco-references目录供新卡面保持身份特征，新卡面另行AI生成，不照搬原构图。页面底部可能含游戏姓名条，生成图要求无字、无框。

结构化资料见[magireco-research.json](magireco-research.json)，使用records数组。id顺序固定mr_0001到mr_0036，appearance来自参考卡图观察，abilities区分剧情能力与原游戏玩法；不把该游戏的数值直接搬入本项目。
