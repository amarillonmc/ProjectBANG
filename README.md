# 时空并错 · 心象实验室

把原设计的普通牌共用、十三张有序心象和人物持续能力做成可试玩的网页卡牌游戏，并提供无需写 JSON 的角色与限定心象牌工坊。

**内测版，PHP + SQLite / MySQL，无构建步骤、无 Composer、无常驻服务。** 前端为原生 HTML/CSS/JavaScript，图片已经包含在项目中。

## 立即试玩

安装 PHP 并启用 PDO SQLite。在项目目录执行：

```sh
php -S 127.0.0.1:8080 -t public
```

如果安装了扩展但尚未启用，例如本次开发使用的 Windows PHP：

```sh
php -d extension=pdo_sqlite -S 127.0.0.1:8080 -t public
```

打开 <http://127.0.0.1:8080>，输入昵称，进入练习对局。真人测试使用创建房间与六位房间码；另一位玩家使用自己的浏览器身份加入。一个浏览器内的多个标签页共享同一席位，模拟两位真人请使用不同浏览器或独立浏览器配置。

Windows 也可在 PowerShell 中执行 `./start.ps1`。PHP 内置服务器只用于本机开发；互联网内测请按下方文档部署到 PHP 主机并使用 HTTPS。

## 交付内容

- 冷暖对抗、系列对抗，2～6 席真人与机器人混合对局。
- 固定 104 张扑克牌池、十三张顺序心象、心坏、角色异色翻面、响应与延时牌。
- 38 位《动物朋友3》角色、76 张主题心象（其中 8 张额外绑定角色），以及原有 4 位示例角色；玄武、青龙、白虎、朱雀四神齐备。
- 35 组经典技能创作拼图、17 种效果积木；支持观星重排、攻防转换、双重防御、赠牌、取牌、拆牌与多次攻击。
- 角色搜索与图库、同 IP 心象牌库、独立载入角色、拼图收藏分享、服务器预算校验与构筑保存。
- 房间邀请、断线恢复、服务器判定、对局记录导出、内测反馈。
- 按 ProjectK 立绘与人设逐位重新生成的 38 张卡面，以及原有肖像图集与心象场景；部署不依赖 ProjectK 或外部图片服务。

原稿没有给出的裁定和本版的范围限制详见规则文档。狼人和天道轮回尚未实现；预算校验不能替代真人平衡测试。

## 目录

```text
public/            唯一推荐 Web 根目录；api.php + 静态前端 + 图片
src/               PHP 规则、引擎、数据库与公共启动代码
var/               自动创建的 SQLite 数据；禁止通过 HTTP 访问
config.example.php 配置模板；复制为 config.php 后修改
docs/              中文文档
tests/             命令行测试；请勿作为网站根目录暴露
tools/             运维检查与打包脚本
```

推荐部署 PHP 8.2 或更新受支持版本，启用 PDO 与对应数据库驱动。代码保持 PHP 7.4 语法兼容以便本次环境验证；不要据此把已停止安全维护的 PHP 版本用于公网。

设计来源：[设计者原帖](https://number81.xyz/index.php?topic=3575.0)。本批内容借鉴《BANG!》《三国杀》的经典范式，角色身份与人设参考 ProjectK 的《动物朋友3》归档；卡面为 AI 重绘。具体改编与证据见内容手册，此项目没有代替原作者决定公开发行许可。
